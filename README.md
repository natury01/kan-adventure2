# ผจญภัยกาญจนบุรี ภาค 2 (kan-adventure2)

เกมการเรียนรู้สังคมศึกษา ชั้น ป.4 · ใช้ภูมิศาสตร์กาญจนบุรีเป็นห้องเรียน · วัดสมรรถนะหลัก 6 ด้านจากพฤติกรรมการเล่นจริง

**เว็บ:** https://gameplearn.com/kan-adventure2
**ภาค 1 (V.7.80):** https://gameplearn.com/kan-adventure — เกมคนละตัว คนละ repo

## โครงในที่เก็บนี้

```
.
├── wrangler.jsonc          ← ตั้งชื่อ Worker + routes + โฟลเดอร์ไฟล์
└── kan-adventure2/         ← ชื่อโฟลเดอร์นี้ = path บนเว็บ (ห้ามเปลี่ยน)
    ├── index.html          ← ตัวเกม (ไฟล์เดียวจบ ~3.9 MB)
    ├── dashboard.html      ← หน้าครู (เครื่องคิดคะแนนสมรรถนะ)
    └── assets/             ← ภาพวาดประกอบฉาก 27 ไฟล์ (.webp)
```

เสิร์ฟด้วย **Cloudflare Workers Static Assets** — ไม่มีโค้ด Worker และไม่ต้อง build
`"directory": "./"` ทำให้ URL `/kan-adventure2/index.html` ตรงกับไฟล์ `kan-adventure2/index.html` โดยตรง

## วิธีอัปเดตเกม

1. เข้าโฟลเดอร์ `kan-adventure2/` → **Add file → Upload files** → ลากไฟล์ใหม่ทับ
2. **Commit changes**
3. Cloudflare deploy อัตโนมัติภายใน 1-2 นาที

ย้อนกลับรุ่นเก่า: Cloudflare → Worker `kan-adventure2` → **Deployments** → **Rollback**
(หรือ revert commit ใน GitHub ก็ได้)

## ข้อควรระวัง

- ห้ามเปลี่ยนชื่อโฟลเดอร์ `kan-adventure2` — ชื่อโฟลเดอร์คือ path บนเว็บ
- ห้ามเปลี่ยนชื่อ `index.html` และห้ามย้ายออกจากโฟลเดอร์
- ต้องมีโฟลเดอร์ `assets/` ครบเสมอ — ถ้าขาด เกมยังเล่นได้แต่จะใช้ฉากวาดด้วยโค้ดแทนภาพจริง
- **อย่าอัปไฟล์ของภาค 1 เข้ามาในนี้** และอย่าอัปไฟล์นี้เข้า repo ของภาค 1

## สิ่งที่เกมนี้ทำ

**ด่านเรือธง 6 ด่าน — 1 ด่าน = 1 สมรรถนะ** วัดจากสิ่งที่เด็ก "ทำ" ไม่ใช่สิ่งที่เด็ก "ตอบ"

| ด่าน | สถานที่จริง | สมรรถนะ |
|---|---|---|
| 🕵️ นักสืบสายมรณะ | สะพานข้ามแม่น้ำแคว + สุสานทหารสัมพันธมิตร | การคิดขั้นสูง |
| 📻 วิทยุนำทางสะพานผา | ถ้ำกระแซ | การสื่อสาร |
| 🎒 แคมป์นักสำรวจ 7 ชั้น | น้ำตกเอราวัณ | การจัดการตนเอง |
| 🚤 กู้ภัยน้ำป่า | เขื่อนศรีนครินทร์/วชิราลงกรณ | การทำงานเป็นทีม |
| 🔎 นักนิเวศน้อย | ต้นจามจุรียักษ์ | ธรรมชาติและวิทยาการ |
| 🏛️ สภาเมืองน้อย | สังขละบุรี เมืองบาดาล | พลเมืองที่เข้มแข็ง |

เก็บ **ตราผู้พิทักษ์ครบ 6 ดวง** → เปิด **ภารกิจรวบยอด "กาญจนบุรี 2050"** (ละครสามองก์ · 70% ของคะแนนสมรรถนะ)
ปิดท้ายด้วย ⚔️ หอคอยปีศาจข้อสอบ (ท้าประลอง + สอบผลสัมฤทธิ์หลังเรียน) และ 🌅 สรุปท้ายคาบ

## เทคนิค

- HTML5 ไฟล์เดียว ไม่มี build step · เล่นผ่านเบราว์เซอร์ทุกเครื่อง
- ทำงานออฟไลน์ได้ — ข้อมูลเข้าคิวในเครื่องแล้วส่งเองเมื่อออนไลน์
- ฐานข้อมูล Supabase (ใช้ร่วมกับภาค 1) — **ความคืบหน้าการเล่นแยกช่องกันเด็ดขาด** (`save_blob2`)
- ทุกแถวข้อมูลติดป้ายเวอร์ชัน `V.8.0-p2-2569.64` แยกรายงานภาค 1/ภาค 2 ได้เสมอ
- ความปลอดภัยเด็ก: ไม่มีแชตอิสระ · ใช้นามแฝง · ไม่เก็บข้อมูลส่วนตัวเกินจำเป็น
