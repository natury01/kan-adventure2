## จุดสำคัญด้านความปลอดภัยและความถูกต้องของข้อมูล

1. **โหมดแขกไม่ส่งข้อมูลขึ้นเซิร์ฟเวอร์เลย** — มีเกราะ 2 ชั้น (ล้างการผูกห้องเรียน + ตรวจชื่อผู้ใช้ก่อนส่ง)
2. **ภาค 2 ไม่เขียนทับเซฟกลางของภาค 1** และไม่รับ "ด่านที่ผ่าน" จากภาค 1
3. **ไม่มีแชตอิสระ · ใช้นามแฝง · ไม่มีเนื้อหาความตาย/บาดเจ็บ**
4. **ภาพจากกล้องในโหมด AR ไม่ถูกบันทึกและไม่ถูกส่งไปไหนทั้งสิ้น** — แสดงบนจอเครื่องนั้นอย่างเดียว ครูปิดทั้งเครื่องได้
5. **ไอเทมชี้คำตอบอยู่ได้เฉพาะสนามที่ไม่คิดคะแนนสมรรถนะ**
6. **สิ่งที่สุ่มได้เปลี่ยนแค่บริบท ไม่เปลี่ยนสิ่งที่วัด** และบันทึกลง `ctx` ให้ตรวจย้อนหลังได้
7. **คลังข้อสอบและสคีมาข้อมูลวิจัยไม่ถูกแตะเลย** — ข้อมูลต่อเนื่องกับของเดิมทั้งหมด

## เปลี่ยนอะไรบ้างในรุ่น V.8.5 (แก้ตามที่ครูแจ้ง)

**ความถูกต้องของข้อมูล**
- โหมดแขกเคยค้างชื่อนักเรียนคนล่าสุด และส่งข้อมูลขึ้นเป็นของคนนั้น → **แก้แล้ว**
- หน้าครูเคยรวมข้อมูลภาค 1 กับภาค 2 ปนกัน → **แยกได้แล้ว** (ค่าเริ่มต้น = ภาค 2)
- ปุ่ม "เข้าสู่ระบบด้วย Google" เคยเรียกฟังก์ชัน "ผูกบัญชี" → เปิดจากเบราว์เซอร์อื่นแล้วห้องเรียนหาย · **แก้แล้ว**
- ชื่อ/อีเมลครูเคยค้างบัญชีเดิมเมื่อสลับบัญชี → ตอนนี้ยึดบัญชีที่ล็อกอินอยู่จริงเสมอ
- ชื่อ Google ภาษาไทยเคยถูกถอดรหัสเพี้ยนแล้วเขียนลงฐานข้อมูล → **แก้แล้ว**
- **ออกจากบัญชีผู้ดูแลแล้วเมนูผู้ดูแลยังค้างอยู่** → ตอนนี้ล้างสิทธิ์ทิ้งทันที ปิดเซสชันที่เซิร์ฟเวอร์ด้วย
  และแถบผู้ดูแลจะไม่โผล่เลยถ้าไม่มีเซสชันจริง

**งานเขียนอัตนัย — เรื่องใหญ่ที่สุดของรอบนี้**
- งานเขียนใน **สมุดนักสำรวจ** (ด่านเรือธงทั้ง 6 ด่าน) เคย **ไม่เข้าหน้าตรวจของครูเลย**
  และถูกให้คะแนนอัตโนมัติ**จากความยาวตัวอักษร**ล้วน ๆ (≥40 ตัว = เต็ม · ≥15 ตัว = 0.7 · ต่ำกว่านั้น = 0.4)
  → เขียนยาวแต่ไม่ตรงประเด็นได้เต็ม · เขียนสั้นแต่คมได้ 0.4 · **ใช้อ้างอิงงานวิจัยไม่ได้**
- ตอนนี้งานเขียนทุกชิ้นขึ้นหน้า 📝 ตรวจสอบอัตนัย ให้ครูให้คะแนน **0-4 พร้อมความเห็น**
  **งานเขียนจะยังไม่เป็นคะแนนเลยจนกว่าครูจะตรวจ** — ค่าที่ระบบประมาณจากความยาวยังโชว์ให้ครูใช้เป็นตัวช่วย
  แต่ไม่ถูกนับเข้าสมรรถนะ และหน้าจอเขียนกำกับไว้ตรง ๆ ว่า "ยังไม่นับเป็นคะแนน"
- คำตอบเขียนกาญ 2050 **กรองตามภาคแล้ว** — ดูภาค 2 อยู่จะไม่มีงานของภาค 1 ปนเข้ามา

### ตัวละครลงไปอยู่ในฉากแล้ว (คำขอครูข้อ 1)

**ข้อค้นพบ:** เครื่องยนต์ตัวละครมีท่าครบ **12 ท่า** อยู่แล้ว (เดิน · กระโดด · ย่อ · กลิ้ง · พายเรือ · ฯลฯ)
แต่ด่านเรือธงไม่เคยเรียกใช้เลยสักท่า — ตัวละครโผล่แค่เป็นบัดดี้มุมจอ
ที่น่าเสียดายคือหน้า "วิธีเล่น" โชว์ภาพท่าเดินกับท่าพายเรือให้เด็กดูอยู่แล้ว แล้วเข้าด่านจริงไปเจออีโมจิ

| ด่าน | เดิม | ตอนนี้ |
|---|---|---|
| **3 สะพานผา** ⭐ | `🚶` ย้ายไปมาระหว่างแผ่นไม้ | **ตัวละครเดินข้ามจริง** · เลือกกระโดด = กระโดดจริง · ก้มลอด = ย่อจริง · หลบรถไฟ = กลิ้งเข้าช่องหลบภัย · พลาด = ท่าเซ |
| **4 แคมป์เอราวัณ** ⭐ | ติ๊กปุ่มแล้วดูตัวเลข กก. | **กระจกส่องเป้** — ติ๊กของแล้วเห็นบนตัวทันที · ตอนปีนแบกของชุดนั้นขึ้นไปด้วย |
| **5 กู้ภัยน้ำป่า** | `🚤` | ตัวละคร **นั่งพายเรือ** ด้วยท่า `paddle` ที่เขียนไว้แล้วแต่ไม่เคยมีด่านไหนเรียก |
| **7 สภาเมืองน้อย** | แตะปุ่มล้วน 100% ไม่มีการเคลื่อนไหวเลย | **เดินไปหย่อนบัตรลงหีบจริง** แล้วดีใจ |
| **เมืองของฉัน** | เมืองไม่มีคนอยู่ | ตัวละคร (พร้อมสัตว์เลี้ยงที่สวมอยู่) **เดินเล่นในเมืองที่เด็กสร้างเอง** |

### เห็นของที่แบกอยู่บนตัวจริง (คำขอครูข้อ 2)

จังหวะเกมทุกด่านเท่าเดิมเป๊ะ · `logEvidence` ได้ค่าเดิมทุกตัว · ทุกด่านมีทางถอยถ้าเครื่องยนต์ตัวละครใช้ไม่ได้

## ระยะ 3 — ความลึกของภาพ (ครูเลือก "เน้นแสงเงาให้ลึกขึ้น")

**เหตุผลที่เลือกทางนี้:** "สมจริงขึ้น" เป็นเรื่องของ **แสง เงา และระยะลึก** ไม่ใช่มุมกล้อง
การเปลี่ยนภาพวาดสวย ๆ ให้เป็นบล็อกสีไอโซเมตริกจะทำให้เกม **ดูสมจริงน้อยลง** ไม่ใช่มากขึ้น
(หลักฐานคือฉากกาญ 2050 ที่ทำมาแล้วและครูให้ถอยกลับไปใช้ภาพวาด)

### ทุกด่านมี "ชั้นความลึก" แล้ว

เพิ่มเข้าไปที่จุดเดียว (`VK.shell`) จึงได้ครบทุกด่านที่ใช้เวทีร่วม — ด่านเรือธง 6 ด่าน · ปริศนาสายน้ำ · เมืองของฉัน

| ชั้น | ทำอะไร |
|---|---|
| **หมอกตามระยะ** | ยิ่งลึกเข้าไปในฉาก (ด้านบน) ยิ่งจาง — เหมือนอากาศบังระยะไกลจริง |
| **แสงอุ่นมุมบนซ้าย** | ทิศเดียวกับเงาของตัวละครและกล่องทุกใบในเกม |
| **ขอบจอมืดลงนิดเดียว** | ดึงสายตาเข้ากลางฉาก |
| **เงาสัมผัสพื้น** | แผ่นไม้ · ช่องกริด · การ์ด · ประตูน้ำ มีเงาติดพื้น ไม่ลอยอีกต่อไป |
| **แสงขอบบน (rim light)** | ขอบที่หันเข้าหาดวงอาทิตย์สว่างกว่าอีกด้าน |
| **พารัลแลกซ์เบา ๆ** | พื้นหลังขยับสวนทางฝั่งที่ผู้เล่นแตะ ให้รู้สึกมีระยะ |

ทั้งหมดเป็น CSS ล้วน **ไม่เปิดลูปวาดเพิ่มแม้แต่ลูปเดียว · ไม่เพิ่มไฟล์ภาพ**
โหมดประหยัดพลังตัดหมอก แสงอุ่น และพารัลแลกซ์ทิ้ง เหลือแค่ขอบจอ

### หมุดบนแผนที่โลกตั้งอยู่บนพื้นแล้ว

โค้ดวาดแท่นไอโซเมตริกใต้หมุดด่าน **เขียนเสร็จและถูกเรียกทุกครั้งอยู่แล้ว แต่ถูก CSS บรรทัดเดียวซ่อนทิ้ง**
(วาดฟรีทุกรอบโดยไม่มีใครเห็น) แยกเป็น 2 โหมดตามชนิดแผนที่:

- **แผนที่ภาพวาด (ค่าเริ่มต้น)** → เงาสัมผัสพื้น + แสงขอบอุ่น ให้หมุดรู้สึกตั้งอยู่บนแผนที่ ไม่ไปทับภาพวาดด้วยบล็อกสี
- **แผนที่เวกเตอร์** → แท่น ISO เต็มรูปแบบตามของเดิม

### ตัวละครคมขึ้นบนแท็บเล็ต

แคนวาสทั้งเกมตรึงที่ 1920×1080 และไม่เคยปรับตามความละเอียดจอเลย → บนแท็บเล็ต Retina ภาพเบลอ
ตอนนี้แคนวาสตัวละครปรับตามจอจริง (สูงสุด 2 เท่า) — **จอ 2 เท่าได้ภาพคมขึ้นจริง** และโหมดประหยัดพลังไม่ขยาย

> ยังไม่แตะแคนวาสหลักของเกม เพราะมีเส้นทาง "กู้คืนเมื่อวาดพัง" 11 จุดที่รีเซ็ตทรานส์ฟอร์ม
> ถ้าใส่สเกลฐานแล้วเส้นทางนั้นทำงาน ภาพจะเพี้ยนถาวรทั้งด่าน — เป็นงานที่ต้องรื้อแยกอีกรอบ

## ระยะ 4 — Co-op ที่วัดได้จริง (9 ส.ค. 2569)

ครูสั่งไว้ว่า *"ไม่ต้องรอผลทดสอบ โรงเรียนส่วนมากเน็ตรับไหว ส่วนโรงเรียนที่เน็ตช้าจริง ๆ ให้เลือกโหมดอื่น"*
จึงทำครบทั้ง 3 ชั้นเลย โดย **ครูไม่ต้องรัน SQL แม้แต่ไฟล์เดียวก็ใช้ได้ครบทุกอย่าง**

### 4A · ในเครื่องเดียว — "ตกลงกันก่อนกด" ที่เป็นจริง

ของเดิม: กดปุ่ม 👥 ทีมผู้พิทักษ์คู่ **ครั้งเดียว** = ได้หลักฐานทำงานเป็นทีมมาฟรี 3 แถว
โดยเกมไม่เคยตรวจเลยว่ามีคนที่สองอยู่จริงไหม (รอบ 17 ปิดคะแนนนั้นไปแล้ว — ระยะ 4 คือคืนคะแนนแบบที่ได้มาจริง)

- เลือกโหมดคู่ → **เลือกที่นั่ง** 🦊 ส้ม · 🐢 เขียว · 🦉 ม่วง · 🐬 ฟ้า (ไม่มีช่องพิมพ์ชื่อจริงเลย)
- **จุดตัดสินใจร่วมองก์ละ 1 จุด** (ตรวจข่าว · ระบบเมือง · คืนพายุ):
  คนแรกเลือก → บอกเหตุผล → คำตอบถูกเบลอ + ส่งเครื่อง → คนที่สองเลือกเองโดยไม่เห็นของคนแรก
  → ตรงกัน **TW-C = 1.0** · ไม่ตรงกันแล้วฟังเหตุผลกันจนตกลงได้ **TW-C = 0.9**
  (สเกลเดียวกับด่าน 5 เป๊ะ เพื่อให้เทียบกันได้ในงานวิจัย)
- **โหมดเดี่ยวก็ได้ฝึก 1 จุด** — สวมสองบทบาท 🧑‍💼 นักวางแผนเมือง / 👵 ตัวแทนชาวบ้าน
- **คืนพายุ**: ต้องกดยืนยันทั้งสองที่นั่งถึงจะไปต่อ — *ตั้งใจไม่ให้คะแนนจากตรงนี้* เพราะการกดปุ่มไม่ใช่หลักฐานสมรรถนะ

### 4B · 🏛️ สภาเมืองของห้อง — ข้ามเครื่องแบบที่เน็ตโรงเรียนรับไหว

ต่อยอด 🏙️ เมืองของฉัน จาก "ส่งขึ้นไปแล้วจบ" เป็นวงจรสองทาง:
ส่งเมือง → เห็นเมืองของเพื่อนทั้งห้อง → 💡 หยิบไอเดียที่เมืองเรายังไม่มีมาวางได้เลย

ยิงเน็ตรวมแล้ว **2 ครั้งต่อคาบ** (ไม่ใช่ถามซ้ำทุก 6 วิแบบห้องเรียนสด)
ไม่เลือกทำเรียลไทม์เพราะต้อง `alter publication` ซึ่งผิดกติกา "SQL เพิ่มอย่างเดียว" และเน็ตโรงเรียนมักบล็อก WebSocket

**ไม่ให้คะแนนสมรรถนะ** — เหรียญของเด็กแต่ละคนไม่เท่ากัน ถ้าให้คะแนนจะกลายเป็นวัด "ใครเล่นนานกว่า"
บันทึกเป็นบริบทให้ครูเห็นว่าเด็กคนไหนดูงานเพื่อนแล้วเอามาปรับของตัวเอง
กระดานแสดง **ชื่อในเกมเท่านั้น** — ไม่มีรหัสนักเรียน ไม่มีชื่อจริง ไม่มีข้อความอิสระ

> ยังไม่รัน SQL = เกมบอกให้ครูฉายกระดานจากหน้าครู (🏙️ เมืองของห้อง) ซึ่งใช้ได้อยู่แล้ว — ไม่มีทางตัน

### 4C · โหมดเครือข่าย 3 ระดับ — ⚙️ ตั้งค่า → 🌐 โหมดเครือข่ายของเครื่องนี้

| โหมด | ทำอะไร | เหมาะกับ |
|---|---|---|
| 🛰️ ออนไลน์เต็ม (ค่าเริ่มต้น) | อัปเดตให้เอง · ห้องเรียนสดถามซ้ำทุก 6 วิ | เน็ตไหลลื่น (ส่วนมาก) |
| 📮 ส่งแล้วดูทีหลัง | แคชกระดานยืดเป็น 10 นาที · ห้องเรียนสดทุก 20 วิ | เน็ตพอไหวแต่ช้า |
| 📵 ในเครื่องล้วน | ไม่ดึงข้อมูลระหว่างเล่นเลย · ห้องเรียนสดเปิดไม่ได้ (บอกเหตุผลตรง ๆ) | เน็ตช้าจริง / หลุดบ่อย |

> **ทั้ง 3 โหมด "ส่ง" ผลการเรียนรู้ขึ้นเซิร์ฟเวอร์เหมือนกันหมด — ต่างกันแค่การ "ดึง" มาแสดง**
> ถ้าโหมดไหนหยุดส่งด้วย ข้อมูลวิจัยจะหายเมื่อเด็กปิดเครื่อง ซึ่งรับไม่ได้ (มีชุดทดสอบยืนยันข้อนี้โดยเฉพาะ)

มีปุ่ม **📶 วัดความเร็วเน็ตแล้วแนะนำให้** — ยิงคำขอจริง 1 ครั้งแล้วบอกว่าควรใช้โหมดไหน
**เกมไม่เปลี่ยนให้เอง** ครูเป็นคนตัดสิน

## รอบตรวจทั้งระบบ (ส.ค. 2569) — บัคที่แก้แล้ว

ตรวจทั้งเกม หน้าครู เส้นทางข้อมูล และความสมเหตุสมผลของระบบ · ทุกข้อ**พิสูจน์ด้วยการรันจริง**
รายละเอียดเต็มอยู่ในไฟล์ `AUDIT_2569-08_และแผนพัฒนา.md`

**ที่ทำให้ข้อมูลวิจัยเสียหาย (แก้แล้วทั้งหมด)**

| # | อาการเดิม |
|---|---|
| A1 | 🧪 โหมดข้อมูลตัวอย่างกด "ยืนยันผล" ได้ → **เขียนทับผลจริงของนักเรียนตัวจริง** ด้วยผลประเมินปลอม · รายงานพิมพ์/CSV ก็ไม่มีคำว่า "ตัวอย่าง" เลย |
| A2 | เด็กออกจากกาญ 2050 กลางคัน → หลักฐานค้างไป**ติดชื่อด่านถัดไปที่เล่น** |
| A3 | โหมดแขก: หลักฐาน**ถูกลบทิ้งถาวร** ไม่ใช่แค่ไม่ส่ง — ล็อกอินทีหลังก็กู้ไม่ได้ |
| A4 | ออกจากระบบแล้วเครื่องยัง "เป็นของ" คนเดิม → เซฟของเด็กคนถัดไปถูกอัปโหลดเป็นของคนก่อน |
| A5 | แท็บเทียบเกณฑ์ · CSV · รายงานพิมพ์ **ยังไม่กรองภาค** (3 เส้นทางแรกแก้ไปแล้ว เหลือเส้นที่ 4) |
| A6 | เด็กเปิดด่านบอสดูแล้วปิด 2 ครั้ง พอสอบจริงครั้งที่ 3 → **คะแนนสอบกลายเป็น 0** |
| A7 | บันทึกเกณฑ์ล้มกลางคัน → ฐานข้อมูลค้างครึ่ง ๆ กลาง ๆ เงียบ ๆ (น้ำหนักเคยกลายเป็น 110%) |
| A8 | คิวส่งข้อมูลทิ้ง**ของเก่าที่สุด**เงียบ ๆ เมื่อเกิน 200 รายการ — เน็ตหลุดยาว = ข้อมูลคาบแรกหายก่อน |

**คะแนนสมรรถนะที่เคยแจกฟรีโดยไม่มีพฤติกรรมรองรับ (อุดแล้ว 5 จุด)**

พิสูจน์ก่อนแก้: เด็กที่แค่**กดเลือก "ลูกเสือ" 1 ครั้ง + จดสมุดข้อความมั่ว 3 ครั้ง** โดยไม่เล่นด่านไหนเลย
ได้ **การสื่อสาร 100% ระดับ 6** และ **การจัดการตนเอง 100% ระดับ 6** — ตอนนี้ทั้งสองด้านขึ้น "ยังไม่มีหลักฐาน" ตามความจริง

- กดเลือกระดับความท้าทาย = ได้ SM-A ฟรี (และค่ากลับหัว: ง่ายสุดได้ 1.0 · มาตรฐานได้ 0.8) → **เก็บเป็นบริบท ไม่ใช่คะแนน**
- กดชิปเริ่มประโยค = ได้ NS-A 0.7 ฟรี → **งานเขียนชิ้นเดียวไม่กลายเป็นคะแนน 2 สมรรถนะอีก**
- สมุดนักสำรวจให้คะแนนจากความยาว → **รอครูตรวจเสมอ**
- กดปุ่ม "โหมดคู่" กาญ 2050 = ได้ TW-C ฟรี 3 แถว ทั้งที่ไม่ตรวจว่ามีคนที่สองจริงไหม → **เก็บเป็นบริบท**
- สลับบทบาทด่าน 5 ยิงหลักฐานตั้งแต่การ์ดโผล่ → **ย้ายไปยิงตอนกดยืนยัน**

**ตรรกะการวัดที่ไม่สมเหตุสมผล (แก้แล้ว)**

- ครูตรวจงานเขียนแล้ว **คะแนนไม่ขยับเลย** ถ้าเด็กเล่นด่านนั้นจบ (ค่าเฉลี่ยด้านย่อยถูกคำนวณแล้วโยนทิ้ง)
  → ตอนนี้หลักฐานระหว่างเรียน = **คุณภาพรวมของด่าน 60% + ด้านย่อย (รวมที่ครูตรวจ) 40%** และเอกสารเกณฑ์อัปเดตตาม
- เล่นกาญ 2050 ซ้ำแล้วทำได้แย่ลง → คะแนนหลักตกทันที ทั้งที่ช่องข้าง ๆ ยังโชว์ครั้งที่ดีที่สุด → **ใช้ครั้งที่ดีที่สุดให้ตรงกันทั้งหน้า**
- เกณฑ์ "ความต่างที่ยอมรับ ±N" นับซ้ำเมื่อ N≥2 และมีรูโหว่เมื่อ N=0 → **เขียนเป็นคู่ตรงข้ามให้ชัด**
- คะแนน AI ที่ตรวจไว้แล้วไม่ถูกใช้เลย ทำให้ตัวเลข**กระโดดในวันที่ครูกดตรวจ** → **ใช้ชั่วคราวพร้อมป้ายว่ารอครูยืนยัน**

**หน้าจอ/การใช้งาน**

- ปุ่ม ⚙️ ตั้งค่าเกณฑ์ บนแถบบน **ไม่กันสิทธิ์ผู้ดูแล** (เกณฑ์นี้กระทบคะแนนนักเรียนทุกคนย้อนหลัง) → กันแล้วทั้งปุ่มและฟังก์ชัน
- เด็กบันทึกสมุด 1 ครั้ง ครูต้องตรวจ 2 รายการ (ข้อความซ้ำ) → **เหลือ 1 รายการ**
- ปุ่ม 📡 ห้องเรียนสด **กดแล้วไม่มีอะไรเกิดขึ้นเลย** → ตอนนี้บอกเหตุผล และซ่อนปุ่มถ้ายังไม่เข้าห้องเรียน
- กล้อง AR **ไม่ปิดตอนเด็กสลับแอป** → ปิดให้อัตโนมัติแล้ว
- คำขอหน้าเทียบเกณฑ์ยัดรหัสนักเรียนทุกคนใน URL เดียว (400 คน ≈ 15 KB) → แบ่งชุดละ 150 คน
- คำตอบเขียนกาญ 2050 **กรองตามภาคแล้ว** — ดูภาค 2 อยู่จะไม่มีงานของภาค 1 ปนเข้ามา

**หน้าครู**
- รวมหน้าเทียบเกณฑ์เข้ากับคะแนนรายห้อง (แท็บ) · สีเหลือ 3 แบบ · ตัดคอลัมน์ "เล่น" ออก (นับจาก event เลยพองเกินจริง)
- **แถบบนสะอาดขึ้น** — ถอดปุ่มที่ซ้ำซ้อนออก (เกมแนะนำ · เกณฑ์ V.8 · เทียบผลการประเมิน · ห้องเรียน · บทเรียนอื่น · เมืองของนักเรียน)
  ชื่อผู้ใช้และบัญชีย้ายไปอยู่**บนสุด** · ปุ่ม ⚙️ ตั้งค่าเกณฑ์ กับ 🖨️ พิมพ์รายงาน ขึ้นมาอยู่แถบแท็บ · ถอดเมนู "สลับบัญชี" ออก (มีปุ่มออกจากระบบอยู่แล้ว)

**เสียงอ่านภาษาไทย**
- มีเสียง **เปรมวดี** ในเครื่อง = เลือกให้อัตโนมัติ ครูไม่ต้องตั้งเอง
- แก้อาการ **อ่านรวดเดียวติดกันเป็นพืด** — หั่นเป็นวลีสั้น ๆ แล้วอ่านทีละวลี จึงมีจังหวะหายใจให้เด็กตามทัน
- ถามเรื่องช่วยอ่านตั้งแต่กด **"เริ่มเกม"** และในหน้า **วิธีเล่น** (จำคำตอบไว้ ไม่ถามซ้ำ)
- ⚠️ เสียง "Online (Natural)" เป็นของ **Edge เท่านั้น** — Chrome บน Windows เห็นแต่เสียงในเครื่อง (Pattara)
  บนมือถือ/แท็บเล็ตไม่มีปัญหานี้ (Android ใช้เสียง Google · iPad ใช้เสียง Siri ภาษาไทย)

**หน้าจอ**
- **ทุกหน้าพอดีจอทั้ง 3 ขนาด** (สมาร์ตโฟน 844×390 · แท็บเล็ต 1024×768 · คอม 1280×720) ไม่มีแถบเลื่อน
- 🎒 เป้ของฉัน → **👗 ห้องแต่งตัว** มีกระจกส่องตัว เห็นผลออร่า/สัตว์เลี้ยงทันทีที่กด
- "เริ่มการผจญภัย" → ไปแผนที่โลก · เพิ่มปุ่ม 🏕️ ห้องพักคอย
- คำว่า "ล็อบบี้" → **"ห้องพักคอย"** ทั้งเกม (หน้าหลักชื่อ "ห้องพักนักผจญภัย")
- ห้องเรียนรู้: ถอดปุ่ม "ไปเล่นด่านนี้เลย" ออก · ปุ่มกลับแผนที่เป็นไอคอนมุมซ้ายบน
- ปุ่ม 👨‍🏫 ออกแบบและพัฒนา — ห้องแต่งตัว/ร้านค้า = มุมขวาล่าง · ห้องพักคอย/เหรียญตรา/อันดับ = มุมซ้ายล่าง

**ฉากกาญจนบุรี 2050**
- กลับไปใช้ภาพวาดในเกมเป็นค่าเริ่มต้น (ภาพวาดประกอบกับฉากเวกเตอร์เป็นคนละภาษาศิลป์)
- ภาพประกอบยังอยู่ครบทุกใบ เปิดเทียบได้ที่ ⚙️ ตั้งค่า → 🖼️ ฉากกาญ 2050 ใช้ภาพวาดประกอบ
- ฉากริมแม่น้ำเติมของให้ไม่โล่ง (หมู่บ้าน แปลงผัก ท่าเรือ กองขยะ ต้นไม้ตาย) และพื้นแห้ง-เขียวตามค่าสิ่งแวดล้อมจริงของเกม

**โหมด AR**
- ใช้ได้เฉพาะเครื่องที่ถือแล้วหันได้จริง — บนคอมพิวเตอร์จะไม่มีปุ่มเปิดกล้อง (กล้องหน้าส่องหน้าเด็ก และยกคอมหันไม่ได้)

## ลำดับที่ควรทำต่อ

1. อัปโฟลเดอร์นี้ขึ้น GitHub repo `kan-adventure2`
2. รัน `SQL_ภาค2_เพิ่มช่องเซฟ.sql` (จำเป็น)
3. ตรวจเช็คลิสต์ในคู่มือ — โดยเฉพาะ *ภาค 1 ยังเปิดได้ปกติ* · *login บัญชีจริงแล้วความคืบหน้าภาค 1 ยังครบ*
4. *(ของแถม)* รัน `SQL_ระยะ4_กระดานสภาเมืองของห้อง.sql` ถ้าอยากให้เด็กเห็นกระดานสภาเมืองบนเครื่องตัวเอง
5. คาบแรกของแต่ละห้อง กด ⚙️ **ตั้งค่า → 📶 วัดความเร็วเน็ตแล้วแนะนำให้** แล้วเลือกโหมดเครือข่ายตามที่แนะนำ
6. ทดลองโหมด 📡 **ห้องเรียนสด** กับห้องจริง 1 คาบ แล้วอ่านสถิติบนแผง (สำเร็จ/ล้ม/หน่วง)
   → ใช้ตัดสินใจว่าจะทำโหมดทีมหลายเครื่องเรียลไทม์เต็มรูปแบบไหม
7. ใส่ชื่อจริง/โรงเรียนบนสไลด์ประกวดหน้า 1
8. ถ้าใช้ Windows: ติดตั้งเสียงไทยแล้วเลือกในเมนู ⚙️ ตั้งค่าของเกม (หรือปล่อยเป็น "อัตโนมัติ")

เจอปัญหาหรือได้ผลทดสอบกับเด็กแล้ว โพสต์ในแชทโปรเจกต์ได้เลยครับ
