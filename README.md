## จุดกันเซฟ 2 ทาง (สำคัญที่สุดของรอบนี้)

ตอนตรวจโค้ดพบว่า **ถ้าใช้บัญชีร่วมกันโดยไม่แก้อะไร ทั้งสองภาคจะเขียนทับกัน** เพราะรหัสด่านซ้ำกัน (ด่าน 1, 3, 4, 5…) แต่เนื้อหาคนละอย่าง และเซฟบนคลาวด์มีช่องเดียวต่อนักเรียน — เด็กที่ผ่านด่านนักสืบในภาค 2 จะกลายเป็น "ผ่านด่าน 1 แล้ว" ในภาค 1 ทันที (และในทางกลับกัน เด็กที่เล่นภาค 1 มาเยอะจะได้ตราผู้พิทักษ์ฟรีในภาค 2 แล้วประตูกาญ 2050 เปิดเองโดยไม่ได้เล่น = หลักฐานสมรรถนะเสียทั้งชุด)

แก้แล้วด้วยการล็อก 2 จุด (แก้ที่ตัวเกมอย่างเดียว ไม่แตะฐานข้อมูล ไม่ต้องรัน SQL)

1. **ภาค 2 ไม่เขียนเซฟกลาง** — ไม่ส่งก้อนเซฟขึ้นคลาวด์เลย ความคืบหน้า/อันดับของภาค 1 จึงปลอดภัย 100%
2. **ภาค 2 ไม่รับ "ด่านที่ผ่าน" จากคลาวด์** — รับเฉพาะเหรียญ ตัวละคร ของสะสม (เด็กไม่รู้สึกว่าเริ่มจากศูนย์)

ทดสอบยืนยันแล้วทั้ง 2 จุด: ยัดเซฟจำลอง "ภาค 1 ผ่านครบ 6 ด่าน" เข้าไป → ภาค 2 ยังไม่มีด่านไหนผ่าน ตรา 0/6 ประตูกาญ 2050 ยังปิด แต่เหรียญ 9,999 เข้ามาครบ ✅

### 🔑 เด็กย้ายเครื่องได้แล้ว — ภาค 2 มีช่องเซฟของตัวเอง

ครูแจ้งว่าคุมให้เด็กใช้เครื่องเดิมไม่ได้ จึงแก้ที่ระบบ: **เพิ่ม "ช่องเซฟภาค 2" แยกอีก 1 ช่องในฐานข้อมูล** (`students.save_blob2` + ฟังก์ชัน `rpc_get_save2` / `rpc_set_save2`)

| | ภาค 1 ใช้ | ภาค 2 ใช้ |
|---|---|---|
| ช่องเซฟ | `save_blob` (ของเดิม) | `save_blob2` (ช่องใหม่) |
| กระดานอันดับ | `collected_score` / `boss_score` | **ไม่แตะเลย** |

**ต้องรันไฟล์ `SQL_ภาค2_เพิ่มช่องเซฟ.sql` ก่อน 1 ครั้ง** (Supabase → SQL Editor → วางทั้งไฟล์ → Run · รันซ้ำได้ ปลอดภัย)
ไฟล์นี้ **เพิ่มอย่างเดียว** — ไม่ลบ ไม่แก้ ไม่ทับตารางหรือฟังก์ชันเดิมแม้แต่ตัวเดียว

> ถ้ายังไม่รัน SQL เกมก็ยังเล่นได้ปกติทุกอย่าง แค่ความคืบหน้ายังไม่ตามข้ามเครื่อง (เก็บในเครื่องเหมือนเดิม)

**ทำงานยังไง:** เซฟทุกครั้ง → อัปขึ้นช่องภาค 2 อัตโนมัติ (หน่วง 3 วิ รวบเป็นครั้งเดียว · เน็ตสะดุดก็ลองใหม่เอง)
เข้าสู่ระบบที่เครื่องไหนก็ตาม → ดึงกลับมาผสานแบบ "เอาค่าที่ดีที่สุด" (ของในเครื่องไม่ถูกลบทิ้ง) — ด่านที่ผ่าน · ตราผู้พิทักษ์ · เหรียญ · สมุดนักสำรวจ ตามไปครบ

ทดสอบแล้ว: เครื่องที่ 1 ผ่านด่านนักสืบ + 320 เหรียญ + จดสมุด 1 บันทึก → ล้างเครื่องจนเกลี้ยงเหมือนเครื่องใหม่ → login → ได้คืนครบทั้ง 4 อย่าง และ **ไม่มีการเรียก `rpc_set_save` ของภาค 1 เลยแม้แต่ครั้งเดียว** ✅

### สิ่งที่ต้องรู้เพิ่ม
- **คะแนนและหลักฐานสมรรถนะทุกชิ้นส่งเข้าฐานข้อมูลตามปกติ** (ไม่ได้อยู่แค่ในเครื่อง) — ครูดูในแดชบอร์ดได้เหมือนเดิม
- **กระดานอันดับในเกมภาค 2 จะยังแสดงตัวเลขของภาค 1** เพราะภาค 2 ไม่แตะคะแนนสรุปของภาค 1 — ถ้าอยากให้ภาค 2 มีกระดานอันดับของตัวเอง บอกผมได้ (เพิ่มอีก 1 คอลัมน์แบบ additive)
- โหมดสาธิต (`?demo=1`) ไม่ส่งอะไรขึ้นเซิร์ฟเวอร์เลยตามเดิม
